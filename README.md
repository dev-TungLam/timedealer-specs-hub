# TimeDealer · Technical Requirements & PRD Portal

A unified, executive-grade product requirement and system architecture portal for **TimeDealer**.

## 📑 Included Specifications
1. **📦 Inventory Network & Stock Sharing** (`inventory-network.html`): B2B shared stock networks, Zero-Vendor-Leak security, and RBAC matrix.
2. **💬 In-App Support Chat** (`in-app-chat.html`): Real-time chat for Mobile App & Admin Web with Guest lifecycle, data merging, and Group-Like View.
3. **🔍 Suggestion Search & AutoComplete** (`suggestion-search.html`): Low-latency Masterfile auto-suggest (&le; 100ms) with Elasticsearch & Auto-Tracking.
4. **📱 WhatsApp OTP Authentication** (`auth-whatsapp-otp.html`): Passwordless registration, login, and reset flow via WhatsApp Business API / WAHA.

## 🚀 Deployment
Deployable with a single command to Vercel:
```bash
npx vercel --prod
```
